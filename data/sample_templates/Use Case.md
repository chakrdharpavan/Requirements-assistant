Use Case:-

Actor:- customer

Pre Condition:-
User is logged in and able to order medicines

Main flow:-

User logged in 
A product grid should be visible
User will choose medicines
User adds relevant medicines to cart
User will share prescription 
Pharmacist will review and approve medicines
User will get a notification
User will pay amount
Delivery agent will receive order
Delivery agent will deliver products to customer

Alternative Flow:-
If medicine stock is not available, system will show a notification this product is available in other brand

Post Condition:-
If prescription not approved customer will come to pharmacy and buy products
